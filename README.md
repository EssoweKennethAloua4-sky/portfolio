# Portfolio d'Essowe Kenneth Aloua

Mon portfolio d'étudiant en informatique orienté cybersécurité : parcours, projets expliqués pour tous, compétences et contact.

## Contenu du dépôt

| Fichier | Rôle |
| --- | --- |
| `index.html` | La page : structure, style, animations |
| `contenu.json` | Tous les textes du site |
| `photo.jpg` | Mon portrait |
| `rapports/` | Les rapports PDF des projets d'infrastructure (Zabbix, SolarWinds NPM) |

## Modifier le site

Tous les textes sont dans `contenu.json`. Pour changer un texte, modifiez ce fichier directement sur GitHub (icône crayon), puis validez avec « Commit changes ». Le site se met à jour en une ou deux minutes.

## Technologies

HTML, CSS et JavaScript, sans framework. Animations avec GSAP et ScrollTrigger. Hébergé gratuitement avec GitHub Pages.
